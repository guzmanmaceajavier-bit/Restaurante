# Sabor y Origen

## Descripción


**Sabor y Origen** es un sistema integral para la gestión y operación de restaurantes, diseñado para centralizar en una sola plataforma los principales procesos relacionados con la atención al cliente, pedidos, reservas, mesas, cocina, ventas, caja, inventario, productos, promociones y administración.


El sistema permite gestionar un catálogo amplio y escalable de productos, incluyendo platos, entradas, comidas rápidas, postres, bebidas y combos, organizados por categorías y con información detallada como precios, ingredientes, imágenes, disponibilidad, características y opciones de personalización.


Los clientes pueden consultar el menú disponible, seleccionar productos, personalizar sus pedidos con adicionales o modificaciones, elegir entre consumo en el restaurante, recogida en el local o domicilio, seleccionar el método de pago y realizar sus pedidos de manera sencilla.


Para el funcionamiento interno del restaurante, el sistema permite administrar pedidos, mesas, reservas y comandas, facilitando la comunicación entre el personal de atención, caja y cocina. Los pedidos pueden avanzar por diferentes estados desde su recepción hasta su preparación y entrega, permitiendo conocer en todo momento el estado de cada orden.


El sistema también incorpora herramientas administrativas para controlar productos, categorías, promociones, combos, clientes, proveedores, compras, inventario y movimientos de caja. De esta manera, el restaurante puede llevar un mejor control de sus operaciones diarias y consultar información relevante para la toma de decisiones.


Sabor y Origen también permite crear **promociones, descuentos, combos y campañas comerciales**, ofreciendo alternativas para atraer nuevos clientes, aumentar las ventas y generar beneficios para clientes frecuentes, sin depender de un sistema tradicional de acumulación de puntos.


Además, cuenta con integración con **WhatsApp** para facilitar la comunicación con los clientes, confirmar reservas, compartir información de pedidos, enviar promociones y mantener diferentes canales de atención.


El sistema incorpora un panel administrativo con estadísticas y reportes sobre ventas, pedidos, productos más vendidos, clientes, reservas, métodos de pago, inventario y comportamiento de las operaciones, permitiendo al administrador obtener una visión general del funcionamiento del restaurante.

## ¿Para quién está hecho?


### Clientes


Está dirigido a personas que desean consultar el menú de un restaurante, conocer sus productos y realizar pedidos de forma rápida y sencilla.


Los clientes pueden:


* Consultar el menú y sus diferentes categorías.
* Buscar y filtrar productos.
* Ver fotografías, precios, ingredientes y características de los platos.
* Personalizar productos y agregar adicionales.
* Realizar pedidos para consumir en el restaurante.
* Solicitar pedidos a domicilio.
* Realizar pedidos para recoger en el establecimiento.
* Programar pedidos para una hora determinada.
* Seleccionar diferentes métodos de pago.
* Reservar mesas.
* Consultar información relacionada con sus pedidos y reservas.
* Recibir promociones y beneficios.
* Comunicarse con el restaurante mediante WhatsApp.
* Calificar su experiencia y dejar reseñas.


### Propietarios y administradores


El sistema está pensado para propietarios, administradores y gerentes que necesitan controlar y supervisar las diferentes áreas del restaurante desde un único lugar.


Permite:


* Administrar productos y categorías.
* Controlar precios y disponibilidad.
* Gestionar pedidos y reservas.
* Administrar mesas.
* Supervisar las operaciones de cocina.
* Gestionar clientes.
* Crear promociones y combos.
* Controlar inventario.
* Gestionar proveedores y compras.
* Administrar caja y ventas.
* Consultar estadísticas y reportes.
* Gestionar usuarios y permisos.
* Supervisar las actividades realizadas dentro del sistema.


### Personal del restaurante


El sistema puede adaptarse a diferentes perfiles de trabajo, permitiendo que cada miembro del equipo acceda a las funciones necesarias para desarrollar sus actividades.


Entre ellos se encuentran:


* Administradores.
* Gerentes.
* Meseros.
* Personal de cocina.
* Cajeros.
* Personal encargado de domicilios.

## Funcionalidades principales


### 🍽️ Gestión del menú y productos


El sistema permite administrar un catálogo amplio de productos sin limitar el restaurante a una cantidad determinada de platos.


Cada restaurante puede crear y organizar sus productos de acuerdo con sus necesidades, incluyendo:


* Platos principales.
* Entradas.
* Comidas rápidas.
* Hamburguesas.
* Carnes.
* Pescados.
* Pollo.
* Pastas.
* Postres.
* Bebidas.
* Combos.
* Productos adicionales.


Cada producto puede contar con nombre, descripción, imagen, precio, categoría, ingredientes, disponibilidad, tiempo de preparación, información de alérgenos, nivel de picante y otras características.


También es posible marcar productos como destacados, recomendados, nuevos, más vendidos o temporalmente agotados.


### 🧀 Personalización de productos


Los productos pueden configurarse con diferentes opciones y adicionales para adaptarse a las preferencias del cliente.


Por ejemplo, un producto puede permitir agregar:


* Queso adicional.
* Tocineta.
* Carne adicional.
* Salsas.
* Papas.
* Bebidas.
* Otros complementos.


También pueden incluirse modificaciones o instrucciones especiales, como retirar determinados ingredientes.


### 🛒 Gestión de pedidos


El sistema permite gestionar pedidos realizados desde diferentes modalidades de servicio:


* Consumo en el restaurante.
* Domicilio.
* Recoger en el establecimiento.


Cada pedido contiene información sobre el cliente, productos, cantidades, modificaciones, adicionales, descuentos, método de pago, tipo de servicio y total de la compra.


Los pedidos pueden avanzar por diferentes estados, permitiendo al personal conocer si una orden está recibida, confirmada, en preparación, lista, entregada o cancelada.


### 👨‍🍳 Gestión de cocina


El personal de cocina puede visualizar las órdenes pendientes de preparación y consultar los productos, cantidades y observaciones solicitadas por los clientes.


Esto facilita el control de las comandas y permite actualizar el estado de los pedidos conforme avanza su preparación.


### 🪑 Gestión de mesas


El restaurante puede administrar sus mesas, indicando su capacidad, ubicación y estado actual.


El sistema permite controlar mesas disponibles, ocupadas, reservadas o en proceso de preparación, además de asociar pedidos a determinadas mesas.


### 📅 Reservas


Los clientes pueden solicitar reservas indicando fecha, hora, cantidad de personas, zona, ocasión especial y observaciones.


El personal del restaurante puede gestionar las reservas, confirmarlas, modificarlas, cancelarlas o reprogramarlas.


También se puede utilizar WhatsApp como medio de comunicación para confirmar o informar sobre una reserva.


### 🎁 Promociones, descuentos y combos


El sistema permite crear diferentes estrategias comerciales para incentivar las ventas.


El administrador puede configurar:


* Descuentos porcentuales.
* Descuentos por valor fijo.
* Promociones 2x1.
* Productos gratis.
* Promociones por categoría.
* Promociones por producto.
* Promociones por días específicos.
* Promociones por horarios.
* Códigos promocionales.
* Combos de productos.
* Ofertas especiales para determinados clientes.


Esto permite al restaurante crear campañas como **"Martes de hamburguesas"**, **"Combo familiar"**, **"2x1 en bebidas"** o **"Postre gratis por cumpleaños"**.


### 👥 Gestión de clientes


El sistema permite registrar y administrar la información de los clientes, así como consultar su historial de pedidos y reservas.


El administrador puede conocer información como frecuencia de compra, número de pedidos, consumo acumulado, última compra y comportamiento general del cliente.


Esta información puede utilizarse para crear campañas y promociones más relevantes.


### 📦 Inventario


El sistema permite controlar los productos e insumos utilizados por el restaurante.


Incluye funcionalidades para:


* Registrar existencias.
* Controlar entradas y salidas.
* Definir cantidades mínimas.
* Generar alertas de bajo inventario.
* Registrar ajustes.
* Consultar movimientos.
* Relacionar productos con sus ingredientes o insumos.


De esta manera, el restaurante puede tener mayor control sobre los recursos utilizados durante su operación.


### 🚚 Proveedores y compras


Permite administrar proveedores y registrar las compras realizadas por el restaurante.


Se pueden registrar productos adquiridos, cantidades, precios, fechas y proveedores, manteniendo un historial de las operaciones realizadas.


Las compras pueden reflejarse en el inventario para mantener actualizadas las existencias.


### 💰 Caja y ventas


El sistema permite controlar las operaciones de caja y registrar las ventas realizadas.


Incluye:


* Apertura de caja.
* Cierre de caja.
* Ingresos.
* Egresos.
* Ventas.
* Descuentos.
* Devoluciones.
* Métodos de pago.
* Historial de movimientos.


Esto facilita el control financiero de las operaciones diarias del restaurante.


### 📊 Dashboard y estadísticas


El panel administrativo proporciona una visión general del funcionamiento del restaurante mediante indicadores y estadísticas.


Entre la información disponible se encuentra:


* Ventas del día.
* Ventas del mes.
* Cantidad de pedidos.
* Reservas.
* Clientes.
* Mesas ocupadas.
* Productos más vendidos.
* Categorías con mayores ventas.
* Horarios de mayor demanda.
* Métodos de pago más utilizados.
* Estado del inventario.


También permite consultar tendencias y comparar el comportamiento de las ventas durante diferentes períodos.


### 📈 Reportes


El sistema permite generar reportes relacionados con las principales áreas del restaurante.


Entre ellos:


* Reportes de ventas.
* Reportes de pedidos.
* Productos más vendidos.
* Reportes de clientes.
* Reservas.
* Inventario.
* Compras.
* Caja.
* Métodos de pago.
* Promociones.


La información puede utilizarse para analizar el funcionamiento del negocio y apoyar la toma de decisiones.


### 📱 Integración con WhatsApp


WhatsApp funciona como un canal adicional de comunicación entre el restaurante y sus clientes.


El sistema permite utilizarlo para:


* Confirmar reservas.
* Compartir información de pedidos.
* Informar sobre pedidos listos.
* Contactar al restaurante.
* Enviar promociones.
* Realizar campañas de comunicación.
* Utilizar plantillas de mensajes.
* Personalizar mensajes con información del cliente y del restaurante.


### ⭐ Reseñas y calificaciones


Los clientes pueden valorar su experiencia mediante un sistema de calificación de una a cinco estrellas y dejar comentarios sobre su experiencia.


El restaurante puede consultar y administrar las reseñas recibidas, permitiendo identificar oportunidades de mejora en la atención y el servicio.


### 🔔 Notificaciones y alertas


El sistema puede generar alertas relacionadas con las operaciones del restaurante, como:


* Nuevos pedidos.
* Pedidos pendientes.
* Reservas próximas.
* Productos agotados.
* Inventario bajo.
* Operaciones de caja pendientes.
* Nuevas reseñas.
* Promociones activas.


### 🔐 Usuarios, roles y permisos


El sistema permite administrar diferentes tipos de usuarios y controlar el acceso a las funcionalidades según las responsabilidades de cada empleado.


Esto permite mantener separadas las funciones administrativas, operativas, de cocina, caja y atención al cliente.


---


## 🎯 Objetivo final


Sabor y Origen busca convertirse en una solución integral para restaurantes que permita **centralizar la operación del negocio, mejorar la atención al cliente, controlar los recursos y obtener información útil para tomar mejores decisiones**.


Más que una simple plataforma para mostrar un menú, el proyecto representa el funcionamiento digital de un restaurante, conectando en un mismo sistema **clientes, pedidos, mesas, reservas, cocina, ventas, caja, inventario, promociones y administración**.
